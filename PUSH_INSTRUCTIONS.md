# Push instructions

1. On GitHub, create a new public repo named exactly `malikaalnajjar` (matching your username). Do not initialize it with a README, license, or gitignore.

2. From this directory:

```bash
   cd malikaalnajjar
   git init
   git add README.md
   git commit -m "Initial profile README"
   git branch -M main
   git remote add origin https://github.com/malikaalnajjar/malikaalnajjar.git
   git push -u origin main
```

3. Visit https://github.com/malikaalnajjar to confirm the README renders on your profile.

4. While there, check:
   - Location is set to Jeddah (Settings > Public profile)
   - Profile picture is set
   - Six repos are pinned in this order: auj, sadeed, saudi-labour-market-analytics (if created), tayseer, masra, plus one cloud/infra repo
   - Each pinned repo has a one-line description and topics (`data-engineering`, `fastapi`, `aws`, `saudi-arabia`, etc.)
